# noScribeEdit

A PyQt6-based rich text editor specifically designed for editing audio transcripts generated by [noScribe](https://github.com/kaixxx/noScribe). This companion editor provides advanced editing capabilities with synchronized audio playback, making transcript review and correction efficient and intuitive.

## Features

-   **Rich Text Editing**: Full formatting support with bold, italic, underline, and text alignment
-   **Synchronized Audio Playback**: Play audio segments that correspond to transcript text with timestamp navigation
-   **Responsive Controls**: Instant pause/play response for smooth editing workflow
-   **Continuous Playback**: Seamlessly plays through transcript segments without interruption
-   **Find & Replace**: Advanced search functionality with case-sensitive and whole-word options
-   **Multiple Export Formats**: Save as HTML, plain text, or WebVTT subtitles
-   **Recent Files**: Quick access to recently opened transcripts
-   **Variable Playback Speed**: Adjust audio speed from 60% to 200% for detailed review
-   **Cross-Platform**: Works on Windows, macOS, and Linux

## Requirements

-   Python 3.8 or higher
-   PyQt6
-   FFmpeg (included in the project for audio processing)

## Installation & Setup

### Quick Start

```bash
# Create virtual environment
python3 -m venv venv

# Activate virtual environment
source venv/bin/activate
# On Windows: venv\Scripts\activate

# Install dependencies
pip install -r environments/requirements.txt

# Run the application
python noScribeEdit.py
```

## Usage

### Opening Transcripts

1. Launch noScribeEdit
2. Use **File > Open** or `Ctrl+O` (`Cmd+O` on Mac) to open a noScribe HTML transcript
3. If prompted, locate the corresponding audio file for synchronized playback

### Audio Playback

-   **Play/Pause**: Click the play button or press `Ctrl+Space` (`Cmd+Space` on Mac)
-   **Speed Control**: Use the dropdown to adjust playback speed (60%-200%)
-   **Navigation**: Click anywhere in the transcript to jump to that audio position
-   **Auto-Follow**: The editor automatically highlights the current audio segment during playback

### Editing Features

-   **Text Formatting**: Use the toolbar buttons or keyboard shortcuts for formatting
-   **Find & Replace**: Press `Ctrl+F` (`Cmd+F` on Mac) to open the search dialog
-   **Undo/Redo**: Standard `Ctrl+Z`/`Ctrl+Y` (`Cmd+Z`/`Cmd+Y` on Mac) support
-   **Auto Speaker Labels**: Press Enter to automatically continue with the same speaker label

### Saving & Export

-   **Save**: `Ctrl+S` (`Cmd+S` on Mac) to save in HTML format
-   **Export Options**:
    -   **HTML**: Full transcript with timestamps and formatting (default)
    -   **TXT**: Plain text version without timestamps
    -   **WebVTT**: Subtitle format compatible with video players and EXMARaLDA

## Workflow with noScribe

noScribeEdit is designed to work seamlessly with transcripts generated by [noScribe](https://github.com/kaixxx/noScribe):

1. **Generate Transcript**: Use noScribe to create an AI-powered transcript from your audio file
2. **Review & Edit**: Open the transcript in noScribeEdit for detailed review and corrections
3. **Audio Synchronization**: The editor automatically links to the original audio file for playback
4. **Final Output**: Export in your preferred format for further use

## Technical Details

### Audio Processing

-   Uses bundled FFmpeg binaries for cross-platform audio support
-   Supports various audio formats (MP3, WAV, M4A, etc.)
-   Creates temporary WAV files for precise seeking and playback
-   Handles variable speed playback with pitch preservation

### File Format

-   Reads noScribe HTML transcripts with embedded timestamp metadata
-   Preserves formatting and speaker information
-   Maintains audio file references for seamless playback

## Troubleshooting

### Audio Issues

-   **No audio playback**: Ensure the original audio file is accessible and hasn't been moved
-   **Audio not found**: Use **File > Audio source** to relocate the audio file
-   **Playback errors**: Check that FFmpeg binaries have proper permissions

### Performance

-   **Slow response**: Ensure you're using the latest version with optimized pause controls
-   **Large files**: Consider breaking very long transcripts into smaller segments
